# CubeSat IoT Disaster Monitoring

This project aims to develop a 3U CubeSat prototype integrating **PCB design, 3D modeling, IoT connectivity, and MATLAB simulations** to monitor natural disasters from space.

## Project Components

1. **PCB Design**
   - Custom electronics for onboard sensors and processing
   - Schematics and Gerber files

2. **3D Design**
   - CAD model for CubeSat structure (3U form factor)
   - Renderings and exploded views

3. **IoT Connectivity**
   - Data transmission from CubeSat to ground
   - Real-time disaster monitoring system

4. **MATLAB Simulations**
   - Orbit analysis, sensor modeling, and system optimization
   - Plots and performance graphs

## Roadmap (15 Days Challenge)
- Day 1–3: PCB design & schematic completion
- Day 4–6: 3D CAD modeling
- Day 7–9: IoT system setup & mock data streaming
- Day 10–12: MATLAB simulations & analytics
- Day 13–14: Integration & testing
- Day 15: Finalize repo, documentation, and visuals
